<h1 align="center">LiveWall</h1>

<p align="center">
  Нативное приложение для macOS, которое воспроизводит видео, картинки и GIF в качестве обоев рабочего стола —

## Требования

- macOS 13 Ventura или новее.
- Apple Silicon или Intel.
- Command Line Tools для сборки из исходников (`xcode-select --install`).

## Сборка из исходников

```bash
git clone https://github.com/BelHetile/LiveWall.git
cd LiveWall
./scripts/build.sh --install
```

- `./scripts/build.sh` собирает `build/LiveWall.app` без установки.
- `./scripts/build.sh --universal` собирает универсальный бинарник (Apple Silicon + Intel).

## Установка

Из релиза:

```bash
curl -fsSL https://raw.githubusercontent.com/BelHetile/LiveWall/main/scripts/install.sh | bash
```

Скрипт скачает последний релиз, установит его в `/Applications` и запустит. Повторный запуск обновляет
приложение.

Из DMG:

1. Скачайте `LiveWall.dmg` из [последнего релиза](https://github.com/BelHetile/LiveWall/releases/latest).
2. Откройте его и дважды щёлкните **Install LiveWall.command**: он скопирует LiveWall в `/Applications`, снимет
   отметку о скачивании и запустит приложение.
3. LiveWall не нотаризован, поэтому macOS один раз переспросит перед запуском установщика:
   - **macOS 15 и новее:** дважды щёлкните команду, затем откройте **Системные настройки → Конфиденциальность и
     безопасность**, прокрутите вниз и нажмите **Всё равно открыть**.
   - **macOS 13–14:** правый клик по **Install LiveWall.command** → **Открыть** → **Открыть**.

   Можно и просто перетащить **LiveWall** в **Программы** вручную — тогда тот же вопрос появится уже для самого
   приложения.

## Возможности

- Видео (mp4, mov, m4v, webm, mkv), картинки (png, jpg, heic, webp) и анимированные GIF в качестве обоев — на
  всех мониторах и рабочих столах (Spaces), под иконками рабочего стола.
- Файлы WebM и MKV (VP9, H.264/HEVC, AV1 на M3 и новее) и MP4 с кодеками, которые macOS не проигрывает,
  перекодируются в HEVC при импорте; у видео, которые показываются чёрными, появляется кнопка **Конвертировать**.
- Обои добавляются кнопкой, перетаскиванием или вставкой ссылки: прямая ссылка на файл, страница, где такой файл
  есть, или YouTube, Vimeo, TikTok и другие сайты, которые поддерживает
  [yt-dlp](https://github.com/yt-dlp/yt-dlp) (плюс [Deno](https://deno.com) для YouTube). Инструменты скачиваются
  при первом использовании после подтверждения либо берутся из Homebrew; обновить их можно в настройках. Видео
  VP8 на Mac не декодируются.
- Свой режим заполнения у каждых обоев (**Заполнить, Вписать, Растянуть, По центру**), своя громкость, звук и
  скорость воспроизведения.
- Умная пауза: воспроизведение останавливается, когда приложение открыто на весь экран или окна закрывают рабочий
  стол, когда активно другое приложение (по желанию), когда Mac работает от батареи, в режиме энергосбережения
  или перегревается (по желанию), когда запущено приложение из заданных пользователем правил, а также когда
  дисплей спит или экран заблокирован.
- Хоткеи: свой переключатель у каждых обоев (рабочий стол, экран блокировки или оба — работает и для обоев из
  закрытых папок), плюс глобальные «следующие / предыдущие / случайные», пауза, режим заполнения, звук и
  библиотека.
- Папки со встроенным набором иконок или своими картинками; папку можно защитить паролем (хранится только как
  хеш PBKDF2-SHA256 с солью; сами файлы не шифруются).
- Синхронизация с экраном блокировки: статичный кадр выбранных обоев — живое видео там macOS не разрешает. Кадр
  выбирается на шкале превью; выключение опции возвращает прежние обои macOS.
- Панель обоев показывает разрешение, частоту кадров и кодек видео.
- Полноэкранная библиотека с живыми превью рабочего стола и экрана блокировки; ползунок на шкале двигает и
  ставит на паузу обои рабочего стола, покадрово.
- **Оптимизировать для этого Mac**: перекодирует видео в HEVC под размер экрана с лимитом 24/30/60 fps; видео,
  которое долго стоит на паузе, выгружается из памяти и заменяется своим же остановленным кадром.
- Автосмена по таймеру — по порядку или случайно; восемь цветовых стилей плюс свои стили файлами `.json`;
  русский и английский интерфейс; запуск при входе в систему.
- Видеообои Wallpaper Engine (`.mp4`) работают напрямую; обои-сцены (`scene.pkg`) работают только внутри
  Wallpaper Engine и на macOS не воспроизводятся.

## Хоткеи

Хоткеи для конкретных обоев задаются в их панели. Глобальные можно изменить или убрать в
**Настройки → Хоткеи**:

| Действие | По умолчанию |
| --- | --- |
| Следующие обои | ⌃⌥⌘→ |
| Предыдущие обои | ⌃⌥⌘← |
| Случайные обои | ⌃⌥⌘R |
| Пауза / продолжить | ⌃⌥⌘Пробел |
| Сменить режим заполнения | ⌃⌥⌘M |
| Звук вкл./выкл. | ⌃⌥⌘S |
| Открыть библиотеку | ⌃⌥⌘L |

Хоткеям не нужны никакие разрешения в Системных настройках. Сочетания, конфликтующие с известными системными
горячими клавишами macOS, не назначаются — LiveWall подсказывает, чем они заняты. Сочетания, занятые другими
приложениями, надёжно определить нельзя: если хоткей не срабатывает, выберите другое сочетание.

## Данные и удаление

- Обои, миниатюры, иконки и скачанные инструменты для видео: `~/Library/Application Support/LiveWall/`
- Настройки: `defaults read io.github.belhetile.livewall`

Удаление:

```bash
curl -fsSL https://raw.githubusercontent.com/BelHetile/LiveWall/main/scripts/uninstall.sh | bash
```

Скрипт удаляет приложение и сохраняет данные. Добавьте ` -s -- --all`, чтобы удалить ещё и обои, настройки,
сохранённое состояние и кеши. Либо просто перетащите LiveWall из «Программ» в Корзину.
