## Требования

- macOS 15 Sequoia или новее.
- Mac на Apple Silicon (M1 или новее).
- По желанию: [Homebrew](https://brew.sh). Через него LiveWall ставит `ffmpeg` (для WebM, MKV, VP8 и AV1 на Mac без
  аппаратного AV1) и `yt-dlp` + `deno` (для ссылок). Перед установкой приложение спрашивает. Для MP4, MOV, GIF и
  картинок ничего дополнительно не нужно.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/BelHetile/LiveWall/main/scripts/install.sh | bash
```

Скрипт скачивает последний релиз, сверяет его с `SHA256SUMS.txt` из релиза, устанавливает в `/Applications` и
запускает. Повторный запуск обновляет приложение.

Или из DMG:

1. Скачайте `LiveWall.dmg` из [последнего релиза](https://github.com/BelHetile/LiveWall/releases/latest).
2. Откройте его и перетащите **LiveWall** в **Программы**.
3. LiveWall не нотаризован, поэтому macOS блокирует первый запуск. Откройте **Системные настройки →
   Конфиденциальность и безопасность**, прокрутите вниз и нажмите **Всё равно открыть**. Либо один раз выполните
   `xattr -dr com.apple.quarantine /Applications/LiveWall.app`.

## Сборка из исходников

Нужны Command Line Tools (`xcode-select --install`) и [rustup](https://rustup.rs); версию Rust задаёт
`rust-toolchain.toml`.

```bash
git clone https://github.com/BelHetile/LiveWall.git
cd LiveWall
./scripts/build.sh --install
```

`./scripts/build.sh` без флага только собирает `build/LiveWall.app`. Про тесты — в
[CONTRIBUTING](.github/CONTRIBUTING.md).

## Возможности

- **Обои:** видео (mp4, mov, m4v, webm, mkv), анимированные GIF и картинки (png, jpg, heic, webp, tiff, bmp) — под
  иконками на всех рабочих столах, включая полноэкранные приложения. Одни обои на все рабочие столы или свои на
  каждом (клавиши 1–9 в библиотеке, ` — для всех).
- **Библиотека:** файлы и папки добавляются кнопкой или перетаскиванием (файлы копируются в библиотеку), можно
  вставить ссылку на видео (в первую очередь YouTube; другие сайты, которые поддерживает
  [yt-dlp](https://github.com/yt-dlp/yt-dlp), могут работать). Новые файлы попадают в открытую папку. Папки — в боковой панели: сразу приватные, если
  нужно, переименование на месте, иконка (SF Symbol или своя картинка) и цвет тега Finder (или любой hex), обои и
  файлы перетаскиваются прямо на папку. Поиск, сетка и список; Delete удаляет обои под курсором.
- **Настройки каждых обоев:** **Заполнить, Вписать, Растянуть, По центру** или **Своё** (положение и масштаб),
  громкость, звук и скорость воспроизведения. Превью в инспекторе можно слушать со звуком, пока копия на рабочем
  столе молчит.
- **Переходы:** растворение, шторка, волна, круг, сдвиг с любой стороны и другие — на GPU.
- **Оптимизировать для этого Mac:** видео перекодируется в HEVC под размер экрана с лимитом частоты кадров
  (VideoToolbox, HDR и 10 бит сохраняются). Новые видео оптимизируются автоматически, если это даёт выигрыш;
  уже лёгкие остаются как есть.
- **Умная пауза:** воспроизведение встаёт на паузу, когда приложение открыто на весь экран, окна закрывают рабочий
  стол, Mac в режиме энергосбережения или перегревается, активно другое приложение (по желанию) или запущено
  приложение из ваших правил; останавливается, пока дисплей спит, экран заблокирован или работает заставка.
  Меню и панель библиотеки показывают, играют ли обои, на паузе или выгружены и почему, а также включён ли звук,
  выключен только у этих обоев или везде. Видео, которое долго стоит на паузе, выгружается из памяти и
  заменяется своим же остановленным кадром. От батареи обои продолжают играть.
- **Экран блокировки:** картинка рабочего стола macOS повторяет обои статичным кадром, поэтому экран блокировки и
  Mission Control совпадают с ними. Кадр выбирается в инспекторе, можно назначить и отдельные обои для экрана
  блокировки. Ваша картинка рабочего стола возвращается, когда LiveWall завершается, — даже после сбоя.
- **Приватные папки:** обои из приватной папки пропадают из библиотеки и меню, пока вы не
  разблокируете их через Touch ID (или пароль Mac). Блокировка заменяет личные обои на рабочем столе безопасными;
  выключите **Настройки → Приватность → Убирать приватные обои с рабочего стола**, чтобы оставить их на рабочем
  столе и экране блокировки (библиотека и меню всё равно их скрывают). Папки снова блокируются при блокировке экрана, сне дисплея,
  после простоя или по ⌃⌥⌘X. По желанию скрывается и сама папка. Это защита от случайного взгляда; файлы не шифруются.
- **Автосмена:** обои меняются по таймеру — по порядку или случайно.
- **Хоткеи, меню и Dock:** глобальные хоткеи, значок в строке меню, запуск при входе. Значок в Dock виден, только
  пока открыто окно библиотеки.
- **Оформление:** светлое, тёмное или как в системе и цветовые стили: «Система» следует акцентному цвету macOS;
  встроены Графит, Секвойя, Гавань, Сумерки, Терракотовый, Песок, Лён и Сланец. Меняйте акцент, оттенок окна или
  любую отдельную часть в разделе **Дополнительно** — первая правка создаёт вашу копию стиля. У каждого цвета есть
  светлый и тёмный вариант (тёмный следует за светлым, пока вы его не зададите), для «Увеличить контраст»
  контрастная версия строится сама, «Уменьшить прозрачность» и «Уменьшить движение» учитываются. Стили
  экспортируются и импортируются файлами `.livewallstyle`.
- **Языки:** русский и английский, по языку macOS. Чтобы выбрать язык только для LiveWall, откройте
  **Системные настройки → Основные → Язык и регион → Приложения** и перезапустите LiveWall.
- **Командная строка:** `lwctl` управляет запущенным приложением (см. ниже).

## Хоткеи

Меняются или убираются в **Settings → Shortcuts**:

| Действие | По умолчанию |
| --- | --- |
| Следующие обои | ⌃⌥⌘→ |
| Предыдущие обои | ⌃⌥⌘← |
| Случайные обои | ⌃⌥⌘R |
| Пауза / продолжить | ⌃⌥⌘Space |
| Звук вкл./выкл. | ⌃⌥⌘M |
| Громче / тише | ⌃⌥⌘↑ / ⌃⌥⌘↓ |
| Заблокировать приватные папки | ⌃⌥⌘X |

Хоткеям не нужны разрешения. Сочетания, которые уже заняты macOS, не назначаются — LiveWall подсказывает, чем они
заняты.

## Командная строка

`lwctl` лежит внутри приложения. При желании добавьте его в `PATH`:

```bash
ln -s /Applications/LiveWall.app/Contents/MacOS/lwctl /usr/local/bin/lwctl
```

`lwctl [--json] <команда>` обращается к запущенному LiveWall. Коды выхода: 0 — успех, 1 — ошибка, 2 — LiveWall не
запущен, 64 — неверный вызов. Список команд и параметры переходов — в [английском README](README.md#command-line)
и в `lwctl --help`.

## Данные

Всё хранится в `~/Library/Application Support/LiveWall/`:

| Путь | Что внутри |
| --- | --- |
| `library.json` | обои, папки, что где показано |
| `settings.json` | настройки и хоткеи |
| `styles.json` | ваши цветовые стили |
| `swap-state.json` | ваши исходные картинки рабочего стола, пока LiveWall их подменяет |
| `Wallpapers/`, `Thumbs/`, `Stills/` | файлы, миниатюры, статичные кадры |
| `private/` | то же для приватных папок (скрыто, доступ только владельцу) |
| `Incoming/` | скачивания в процессе |

## Удаление

Завершите LiveWall из строки меню (картинка рабочего стола вернётся), затем удалите `/Applications/LiveWall.app`.
Чтобы удалить и обои с настройками, удалите `~/Library/Application Support/LiveWall`.
