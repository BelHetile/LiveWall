LiveWall ставит на рабочий стол видео, картинки и GIF — как Wallpaper Engine на Windows. Это небольшое нативное
приложение на Swift: видео декодируется железом Mac, воспроизведение само встаёт на паузу, когда рабочего стола не
видно, а управлять всем можно из окна библиотеки, меню в строке меню или глобальными хоткеями.

## Установка

**Одной командой** (рекомендуется) — вставьте в Терминал:

```bash
curl -fsSL https://raw.githubusercontent.com/BelHetile/LiveWall/main/install.sh | bash
```

Команда скачает последний релиз, положит LiveWall в **Программы** и запустит. Чтобы обновиться, выполните её ещё раз.

<details>
<summary><b>Или установите DMG вручную</b></summary>

1. Скачайте **LiveWall.dmg** из [последнего релиза](https://github.com/BelHetile/LiveWall/releases/latest).
2. Откройте его и перетащите **LiveWall** в **Программы**.
3. При первом запуске macOS скажет, что не может проверить разработчика (LiveWall бесплатный и не нотаризован Apple):
   - **macOS 15 и новее:** один раз откройте LiveWall, затем **Системные настройки → Конфиденциальность и
     безопасность**, прокрутите вниз и нажмите **Всё равно открыть**.
   - **macOS 13–14:** правый клик по LiveWall в «Программах» → **Открыть** → **Открыть**.

</details>

<details>
<summary><b>Или соберите из исходников</b></summary>

Нужны Command Line Tools (`xcode-select --install`).

```bash
git clone https://github.com/BelHetile/LiveWall.git
cd LiveWall
./build.sh --install
```

`./build.sh` без флагов просто соберёт `build/LiveWall.app`; `./build.sh --universal` соберёт для Apple Silicon и Intel.

</details>

**Требования:** macOS 13 Ventura или новее, Apple Silicon или Intel.

## Возможности

**Обои**
- Видео (mp4, mov, m4v — H.264/HEVC), картинки (png, jpg, heic, webp) и анимированные GIF.
- Добавление кнопкой **Добавить**, перетаскиванием файлов, папок и ссылок в окно или вставкой ссылки (**⌘V**).
  Ссылка может вести прямо на файл или на страницу, где он есть.
- Свой режим заполнения у каждых обоев: **Заполнить, Вписать, Растянуть, По центру**. Своя громкость, звук и скорость.
- Работает на всех мониторах и во всех рабочих столах (Spaces), под иконками рабочего стола. Плавная смена обоев.

**Библиотека**
- Полноэкранная библиотека с живыми превью **рабочего стола** и **экрана блокировки**.
- Клик по обоям открывает панель: поставить на рабочий стол или экран блокировки, пауза, громкость, скорость, режим
  заполнения, папка и хоткей.
- **Папки** с набором иконок (54 иконки × 8 цветов) или своими картинками; обои перетаскиваются прямо на папку.
- **Закрытые папки**: пароль на папку — её обои исчезают из библиотеки, меню и «Следующие/Случайные», пока папку
  не откроют.
- Переименование двойным кликом.

**Хоткеи**
- Свой хоткей у любых обоев: нажали — поставились эти обои, нажали ещё раз — вернулись прежние. Хоткей может менять
  рабочий стол, экран блокировки или оба, и работает даже для обоев из закрытых папок.
- Глобальные хоткеи: следующие / предыдущие / случайные, пауза, режим заполнения, звук, открыть библиотеку.

**Умная пауза** (как настройки производительности в Wallpaper Engine) — видео встаёт на паузу, когда:
- приложение открыто на весь экран или окна закрывают рабочий стол;
- активно другое приложение (по желанию);
- Mac работает от батареи (по желанию), в режиме энергосбережения или перегревается;
- запущено или активно приложение из **правил приложений** (например, игра);
- дисплей спит или экран заблокирован.

**А ещё**
- Экран блокировки: статичный кадр выбранных обоев (живое видео там macOS не разрешает).
- Автосмена по таймеру — по порядку или случайно.
- 8 цветовых стилей, свои стили (передаются файлами `.json`), русский и английский интерфейс.
- Запуск при входе в систему, иконка в Доке (можно выключить), меню в строке меню.

## Хоткеи

Хоткеи для конкретных обоев задаются в их панели — пока вы не выберете сочетание, его нет. Глобальные можно
изменить или убрать в **Настройки → Хоткеи**:

| Действие | По умолчанию |
| --- | --- |
| Следующие обои | ⌃⌥⌘→ |
| Предыдущие обои | ⌃⌥⌘← |
| Случайные обои | ⌃⌥⌘R |
| Пауза / продолжить | ⌃⌥⌘Пробел |
| Сменить режим заполнения | ⌃⌥⌘M |
| Звук вкл./выкл. | ⌃⌥⌘S |
| Открыть библиотеку | ⌃⌥⌘L |

Хоткеям не нужны никакие разрешения в Системных настройках.

## Полезно знать

- **Батарея.** Аппаратное декодирование держит расход низким, но полноэкранное видео всё равно тратит немного
  энергии. Умная пауза останавливает видео, когда рабочего стола не видно; включите «Mac работает от батареи» в
  настройках, чтобы обои вставали на паузу от батареи.
- **Экран блокировки.** macOS не даёт приложениям показывать живое видео на экране блокировки, поэтому LiveWall
  ставит туда статичный кадр (Wallpaper Engine на Windows делает так же).
- **Закрытые папки** скрывают обои внутри LiveWall. Пароль хранится только как хеш PBKDF2-SHA256 с солью, восстановить
  его нельзя. Сами файлы на диске не шифруются.
- **Wallpaper Engine.** Видеообои (`.mp4`) работают сразу. Обои-*сцены* (`scene.pkg`) работают только внутри
  Wallpaper Engine и на Mac не воспроизводятся.
- **Ссылки.** Сайты, которые не отдают файл напрямую (YouTube и подобные), не поддерживаются.

## Где лежат данные

- Обои, миниатюры и иконки: `~/Library/Application Support/LiveWall/`
- Настройки: `defaults read io.github.belhetile.livewall`

## Удаление

```bash
curl -fsSL https://raw.githubusercontent.com/BelHetile/LiveWall/main/uninstall.sh | bash
```

Добавьте в конце ` -s -- --all`, чтобы удалить ещё и обои с настройками. Или просто перетащите LiveWall из
«Программ» в Корзину.

## Файлы цветовых стилей

Стили — это небольшие JSON-файлы, которыми можно делиться (**Настройки → Цветовой стиль → Экспорт / Импорт**):

```json
{ "id": "my-style", "name": "Midnight", "primary": "#3B5BDB", "secondary": "#AE3EC9" }
```
